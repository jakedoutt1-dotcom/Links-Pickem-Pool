# Last Alibi guided cases

New rooms explicitly choose Solo, Solve Together (2–8 investigators), or Secret Killer (4–8 guests). Solo and Solve Together create six fictional suspects; investigators never receive the solution. In Secret Killer, one player receives a private culprit role. The TV receives only public information and cannot join a seat or control the case.

New rooms use `flowVersion: 2`. Each scene provides an objective and a discussion prompt. During Acts II and IV, each player saves a private suspect-and-evidence theory before marking ready. Theories can be revised during that scene; other players see only completion progress. The host can continue as soon as everyone is ready. Older active rooms retain their original readiness rules.

The optional deduction board lets each player mark any suspect as unconfirmed, having an alibi, or suspected, and attach one discovered or shared record. These are the player's judgments; the game does not verify them or reveal any solution. Marks are saved to that player's seat for the current case and never appear in another player's or the TV's view. A suspected guest and attached record can be carried into the existing theory or accusation form with an explicit button; the player still reviews and submits it. The board locks when that player seals an accusation. Private notebook drafts survive polling, scene navigation and reload in the same browser tab; the Save button persists them to the room. A new case clears both notes and deductions.

The host can mark an unfinished guest away during an active scene, preserving their role, discoveries, notes and suspect character. Away guests do not count toward readiness, accusation quorum or the final majority and earn no points if still away when the case closes. A guest who has sealed an accusation cannot be marked away. Away guests read along and can rejoin from their own phone before the case ends; returning clears their ready flag so they must finish the current scene. Only the host can manage other seats, and only in the lobby can the host remove a stale guest seat. The host cannot mark themself away. Rematches reset the remaining seats to active and unready, allowing stale seats to be removed before another case begins.

Standard difficulty uses synchronized recording clocks. Expert difficulty requires correcting the device timestamps. Both retain the earlier recording that looks convincing but does not cover the attack window. Case generation verifies one solution and avoids consecutive culprit characters, methods, and scenes where possible.

Each investigator seals a suspect, location, method, and supporting shared record. A strict majority of players taking part identifying the culprit solves the case. Correct suspect earns 500 points; correct scene and method add 100 each. In Secret Killer, an active uncaught culprit earns 500. Scores are saved once when the case ends. The host then reveals the timeline, culprit, explanation, and scores in synchronized steps across phones and TV. Private theories become personal feedback at the final step, alongside a personal who/where/how review, the player's saved deduction board and private notebook. The TV receives none of that personal reasoning.

Original procedural ambience and effects run on the device. The optional narrator uses available browser voices, with voice selection, replay, captions, music ducking, and a shared mute control. Solo and TV default to narration after a user gesture; multiplayer phones default to narrator off. No paid voice service or recorded actor is required. Actual voice timbre depends on the device.

Checks include generated-case uniqueness, private views, theory readiness, pause enforcement, reveal permissions, legacy compatibility, rematch cleanup, and scoreboard idempotence in `tests/last-alibi-flow.mjs`; deduction privacy, recovery permissions, active majority and persisted scores in `tests/party-playability-regressions.mjs`; audio lifecycle in `tests/last-alibi-audio.mjs`; and solo/group phone and TV interactions in the browser suites. Browser flows cover deduction-to-theory/accusation handoff, private case reviews, away/return, and draft preservation across polls, navigation, reload and typing during a save.
