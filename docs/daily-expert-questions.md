# Daily Challenge expert final bank

Verified October 20, 2026. `functions/lib/daily-expert-bank.js` is a **server-only** bank of twelve original, short multiple-choice questions. Each has four distinct options, one correct answer, a concise explanation, and a primary-source URL. The browser must receive only the stem/options before submission; answer and explanation belong in the reveal.

These are intended as a materially harder fifth question after an easy → medium → medium → hard progression. Difficulty is an editorial judgment, not a calibrated guarantee. Monitor fifth-question accuracy by question ID after sufficient plays, replacing ambiguous items rather than shortening the timer to manufacture difficulty. A knowledgeable specialist may find a particular final easy.
