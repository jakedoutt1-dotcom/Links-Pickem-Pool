    How Daily Shot works

    Everyone plays the same five positions each day. A clean swish earns 20 points; a made shot that touches the rim or backboard earns 10. Misses earn zero. Each ranked run has five shots. You get three ranked runs per day; only your best completed run counts. Starting a ranked run uses one attempt, and unfinished runs can be resumed for up to 20 minutes or until midnight Central, whichever comes first. Finishing a daily run builds your play streak. Practice is unlimited and never changes the ranked standings.
