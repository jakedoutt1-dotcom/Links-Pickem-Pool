YOUR QUESTION LIBRARY

Keep it fresh.

Change the questions, not the database

  1. Sign in to your pool as commissioner. Open Trivia Night → Set up a game → Manage questions.
  2. Download the current library. Keep a backup before editing.
  3. Edit the JSON file using the example below. You can replace questions or add more.
  4. Upload the file, review the question count, then press Replace question library.

Imports replace this pool’s library, up to 500 questions. Other pools are unaffected. Active rooms keep their question snapshot; creating a room or starting another game loads the latest library. No database credentials or database switch is needed.

Categories: football, music, movies, history, science, general. Difficulty: easy, medium, hard. Correct: 0 is the first answer, 1 the second, 2 the third, 3 the fourth. Each question must have a unique ID and four distinct answers. Check answers and difficulty before hosting.

Free question sources

Open Trivia DB and OpenTriviaQA offer question banks under CC BY-SA 4.0. Preserve attribution, license and change notices. Convert their fields to the example format before uploading; external API files are not imported directly. The starter bank uses original LINKS questions.

For an adapted question, include the source URL and credit in source; use a license value such as “CC BY-SA 4.0; wording adapted; https://creativecommons.org/licenses/by-sa/4.0/”. These are shown after the reveal and included in your library export. Do not import copied Jeopardy archive clues without permission.

Run the night

Share the QR code or room code. Each player or team uses one phone; no account is required for guests. The lobby shows a large QR code and joined players. Press Start game, choose a category, then press Start question to begin the timer. Wait for its timer, and reveal when ready. After a regular answer reveal, Final round launches a reserved hard question: 20 seconds, double base and speed points (3,000–4,000). Reveal it so everyone can see the correct answer, then press Show final standings to finish. If your custom library has no suitable hard question, the final-round button is unavailable; add more hard questions for the next game. Late arrivals start on the next question with zero points. You can pause between questions for as long as you want, up to the room’s 24-hour lifetime. End the game whenever you are ready, then play another with everyone still joined.

Easy: 10 seconds and 500 base points. Medium: 15 seconds and 1,000. Hard: 20 seconds and 1,500. A correct answer adds up to 500 speed points based on the fraction of time remaining when the server receives it. Wrong or late answers earn zero. The server locks each submitted answer. Ties share rank; speed already affects scores. A room supports up to 200 participants, but this is a software limit, not a tested traffic capacity.

No questions repeat within a game. Starting another game can reuse questions. The initial library has 51 questions, including just three samples per non-football category. Add reviewed questions before hosting a full event. Scores are for this room only and do not affect the existing football challenge or pool standings.
