A QUICK NOTE ABOUT EXCEL

What are macros?

Macros are small built-in instructions that make the workbook’s pick buttons work, save and load picks, and refresh NFL scores. They handle the repetitive work for you.

These tools need desktop Microsoft Excel. They will not run in a browser, an email preview, or a phone’s spreadsheet app. Keep the file as .xlsm so its tools stay included.

Windows: enable the workbook’s tools
  1. Extract the ZIP and open the workbook in desktop Excel.
  2. For this trusted download, choose Enable Editing and Enable Content if Excel asks.
  3. If Excel says Microsoft has blocked macros, close Excel. Right-click the extracted .xlsm file → Properties → General. If Unblock is shown, check it, choose Apply / OK, and reopen the workbook.

If your workplace blocks the change, ask your IT contact. Microsoft’s Windows help ↗

Mac: complete the one-time setup
  1. Unzip the package and follow its READ ME FIRST instructions.
  2. Run the included Mac helper setup once, as the guide explains.
  3. Open the workbook in desktop Excel and choose Enable Macros for this trusted file when prompted.

The guide also explains what to do if no prompt appears. Microsoft’s Mac help ↗

Enable macros only for a file you trust. You do not need to turn on all macros or lower security for every workbook.
