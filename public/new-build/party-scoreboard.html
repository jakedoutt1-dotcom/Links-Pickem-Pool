How results count

Finished multiplayer games count automatically for guests and members. Multiplayer wins require at least two players. Practice, unfinished rooms and solo trivia do not. Goal Line has its own solo high-score board: finish a run and choose Save this score. Goal Line does not earn multiplayer wins. Shared winners each earn a win. Last Alibi uses the mystery outcome; Dead Air uses transmitter progress, then points. Other games use their final winners or top scores.

Points stay within their own game. Difficulty, room size and mode can affect high scores, so these are friendly records, not a tournament rating. Records begin with this update; expired games from before it cannot be recovered.

Two people with the same name keep separate records. Guest results are saved automatically when a multiplayer game finishes. Goal Line guest records stay linked on this browser; use the same device to build your record.
